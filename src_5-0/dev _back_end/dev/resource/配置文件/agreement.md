# Modbus通信协议规范

> 协议版本: v2.1
> 更新日期: 2026-04-24
> 适配标准: Modbus RTU (通过4G TCP透传)

---

## 概述

本协议定义了模组与服务器之间的Modbus通信格式，采用简化的Modbus RTU-over-TCP封装。
由于采用4G TCP透传方式传输，协议中省略了传统Modbus RTU中的从站地址字段(从站地址由模组自行管理)和CRC16校验字段(TCP层已提供可靠性保障)，保留了Modbus RTU的核心功能码和数据格式。

---

## 帧结构

### 标准Modbus RTU帧格式

```
[从站地址] [功能码] [数据] [CRC16低字节] [CRC16高字节]
```

### 本协议采用的帧格式

```
[功能码] [数据]
```

**说明:**
- 省略从站地址: 模组作为Modbus主站直接管理从站地址，服务器无需指定
- 省略CRC16: 4G TCP传输层已提供数据完整性校验
- 功能码与数据格式: 保持与标准Modbus RTU一致

---

## 功能码列表

| 功能码 | 方向 | 名称 | Modbus标准对应 |
|:------:|:----:|------|----------------|
| 00 | 上发 | 心跳包 | 非标准，用于维持连接 |
| 01 | 下发/上发 | 模组配置查询/上发 | 非标准，模组参数管理 |
| 02 | 下发/上发 | 模组配置下发/结果 | 非标准，模组参数管理 |
| 03 | 下发/上发 | 数据配置查询/上发 | 非标准，轮询配置管理 |
| 04 | 下发/上发 | 数据配置下发/结果 | 非标准，轮询配置管理 |
| 05 | 上发 | 数据上发 | 非标准，数据上报 |
| 06 | 下发/上发 | 远程置数 | 标准功能码 0x06 (写单个寄存器) |

---

## 字节序约定

本协议所有多字节数据均采用 **大端序 (Big Endian)**，即高字节在前，低字节在后。

**示例:** 寄存器地址 0x1234 表示为 `[0x12] [0x34]`

## 详细协议定义

### 00 - 心跳包

**功能:** 模组定期上发的心跳信号，用于维持TCP连接存活

```
请求帧 (模组→服务器):
[功能码(0x00)]

响应帧 (服务器→模组):
[功能码(0x00)]
```

**说明:** 无实际数据内容，仅功能码

---

### 01 - 模组配置

#### 下发01 - 模组配置查询

**功能:** 服务器查询模组的通信参数配置

```
请求帧 (服务器→模组):
[功能码(0x01)]
```

#### 上发01 - 上发模组配置

**功能:** 模组上送当前通信参数配置

```
响应帧 (模组→服务器):
[功能码(0x01)] [发送模式(1字节)] [配置数据(2字节)] [波特率(1字节)]

字段说明:
┌─────────────┬──────────────────────────────────────────────────────┐
│ 发送模式    │ 0x00: 定时发送                                        │
│             │ 0x01: 线圈置1触发发送                                 │
│             │ 0x02: 线圈状态变化触发发送                             │
├─────────────┼──────────────────────────────────────────────────────┤
│ 配置数据    │ 定时发送模式: 发送间隔(秒)                             │
│             │ 触发模式: 触发线圈地址                                 │
├─────────────┼──────────────────────────────────────────────────────┤
│ 波特率      │ 见波特率配置表                                         │
└─────────────┴──────────────────────────────────────────────────────┘
```

---

### 02 - 模组配置下发

#### 下发02 - 下发模组配置

**功能:** 服务器向模组下发通信参数配置

```
请求帧 (服务器→模组):
[功能码(0x02)] [发送模式(1字节)] [配置数据(2字节)] [波特率(1字节)]
共计: 5字节
```

#### 上发02 - 模组配置结果

**功能:** 模组返回配置执行结果

```
响应帧 (模组→服务器):
[功能码(0x02)] [成功状态(1字节)]

成功状态:
┌──────┬─────────────────────────┐
│ 0x00 │ 成功                     │
│ 0x01 │ 打开存储错误             │
│ 0x02 │ 写入存储失败             │
│ 0x03 │ 触发模式错误             │
│ 0x04 │ 数据接收长度错误         │
│ 0x05 │ 波特率配置错误           │
└──────┴─────────────────────────┘
```

---

### 03 - 数据配置

#### 下发03 - 数据配置查询

**功能:** 服务器查询模组的轮询数据配置

```
请求帧 (服务器→模组):
[功能码(0x03)]
```

#### 上发03 - 数据配置上发

**功能:** 模组上送当前轮询数据配置列表

```
响应帧 (模组→服务器):
[功能码(0x03)] [数据数量(2字节)] [数据项...]

数据项格式:
[从站地址(1字节)] [类型(1字节)] [数据地址(2字节)] [数据长度(2字节)]

数据类型 (对应Modbus区域):
┌──────┬──────────────────┬────────────────┬────────────────────┐
│ 类型值│ Modbus区域       │ 名称            │ 读写特性            │
├──────┼──────────────────┼────────────────┼────────────────────┤
│ 0x00 │ 0区 (00001-09999)│ Coil (线圈)     │ 读写，单Bit         │
│ 0x01 │ 1区 (10001-19999)│ Discrete Input │ 只读，单Bit         │
│ 0x02 │ 3区 (30001-39999)│ Input Register  │ 只读，16-bit        │
│ 0x03 │ 4区 (40001-49999)│ Holding Register│ 读写，16-bit        │
│ 0x04 │ 扩展类型         │ Extended        │ 厂商自定义         │
└──────┴──────────────────┴────────────────┴────────────────────┘
```

**地址映射说明:**
- 本协议中地址直接使用Modbus协议地址数值
- 模组内部需将协议地址转换为Modbus RTU标准格式:
  - Coil/Discrete Input: 地址作为Bit偏移量
  - Holding Register/Input Register: 地址作为寄存器偏移量

---

### 04 - 数据配置下发

#### 下发04 - 数据配置下发

**功能:** 服务器向模组下发轮询数据配置列表

```
请求帧 (服务器→模组):
[功能码(0x04)] [数据数量(2字节)] [数据项...]

数据项格式:
[从站地址(1字节)] [类型(1字节)] [数据地址(2字节)] [数据长度(2字节)]
```

#### 上发04 - 数据配置结果

**功能:** 模组返回配置执行结果

```
响应帧 (模组→服务器):
[功能码(0x04)] [成功状态(1字节)]

成功状态:
┌──────┬─────────────────┐
│ 0x00 │ 配置成功         │
│ 0x01 │ 打开文件错误     │
│ 0x02 │ 写入文件错误     │
│ 0x03 │ 数据类型错误     │
│ 0x04 │ 查询数据越界     │
│ 0x05 │ 数据接收长度错误 │
└──────┴─────────────────┘
```

---

### 05 - 数据上发

#### 上发05 - 数据上发

**功能:** 模组上报采集到的Modbus数据

```
请求帧 (模组→服务器):
[功能码(0x05)] [数据数量(2字节)] [数据项...]

数据项格式:
[从站地址(1字节)] [类型(1字节)] [数据地址(2字节)] [数据长度(2字节)] [数据值(变长)]

字段说明:
┌─────────────┬────────────────────────────────────────────────────────┐
│ 数据地址    │ 大端序，Modbus寄存器地址                                 │
├─────────────┼────────────────────────────────────────────────────────┤
│ 数据长度    │ 大端序，表示寄存器/线圈数量                               │
├─────────────┼────────────────────────────────────────────────────────┤
│ 数据值长度  │ Coil/Discrete Input: ceil(数据长度 / 8) 字节            │
│             │ Holding Register/Input Register: 数据长度 × 2 字节      │
└─────────────┴────────────────────────────────────────────────────────┘
```

**数据值编码规则 (与Modbus RTU标准一致):**
- Coil/Discrete Input: 按Bit排列，每字节8个Bit，高位在前
- Holding Register/Input Register: 每寄存器2字节，高字节在前

---

### 06 - 远程置数

#### 下发06 - 远程置数

**功能:** 服务器通过模组远程写入设备寄存器/线圈 (对应Modbus标准功能码 0x05写单个线圈、0x06写单个寄存器，本协议合并为批量操作)

```
请求帧 (服务器→模组):
[功能码(0x06)] [类型(1字节)] [开始地址(2字节)] [数量(2字节)] [数值(变长)]

字段说明:
┌─────────────┬────────────────────────────────────────────────────────┐
│ 类型        │ 0x00: Coil (线圈) - 写单个Bit                           │
│             │ 0x04: Holding Register (保持寄存器) - 写16-bit寄存器   │
├─────────────┼────────────────────────────────────────────────────────┤
│ 开始地址    │ 大端序，Modbus寄存器地址                                 │
├─────────────┼────────────────────────────────────────────────────────┤
│ 数量        │ 大端序，写入的寄存器/Bit数量                             │
├─────────────┼────────────────────────────────────────────────────────┤
│ 数值长度    │ Coil: ceil(数量 / 8) 字节                               │
│             │ Holding Register: 数量 × 2 字节                         │
└─────────────┴────────────────────────────────────────────────────────┘

数值编码规则:
- Coil: 每Bit代表一个线圈状态，高位在前
- Holding Register: 每寄存器2字节，高字节在前 (大端序)
```

**Modbus标准映射:**
| 本协议类型 | Modbus功能码 | 说明 |
|:----------:|:------------:|------|
| 0x00 (Coil) | 0x05 (写单个线圈) | 扩展为批量操作 |
| 0x04 (Holding Register) | 0x06 (写单个寄存器) | 扩展为批量操作 |

#### 上发06 - 远程置数结果

**功能:** 模组返回远程写入操作的结果

```
响应帧 (模组→服务器):
[功能码(0x06)] [类型(1字节)] [开始地址(2字节)] [数量(2字节)] [成功状态(1字节)]

成功状态:
┌──────┬─────────────────────┐
│ 0x00 │ 成功                 │
│ 0x01 │ 发送Modbus报文失败   │
│ 0x02 │ 解析Modbus报文失败   │
│ 0x03 │ 数据包长度错误       │
│ 0x04 │ 地址越界             │
│ 0x05 │ 功能码错误           │
│ 0x06 │ 数据包小于最小长度   │
└──────┴─────────────────────┘
```

## 数据类型详解 (Modbus区域映射)

### 标准Modbus地址区域

| 区域 | 地址范围 | 名称 | 数据大小 | 访问类型 | 功能码 |
|:----:|:--------:|------|:--------:|:--------:|--------|
| 0区  | 00001-09999 | Coil | 1 Bit | 读写 | 0x01, 0x05, 0x0F |
| 1区  | 10001-19999 | Discrete Input | 1 Bit | 只读 | 0x02 |
| 3区  | 30001-39999 | Input Register | 16 Bit | 只读 | 0x04 |
| 4区  | 40001-49999 | Holding Register | 16 Bit | 读写 | 0x03, 0x06, 0x10 |

### 本协议地址映射

| 类型值 | 对应区域 | 说明 |
|:------:|:--------:|------|
| 0x00 | 0区 (00001-09999) | Coil，写操作对应Modbus 0x05功能码 |
| 0x01 | 1区 (10001-19999) | Discrete Input |
| 0x02 | 3区 (30001-39999) | Input Register |
| 0x03 | 4区 (40001-49999) | Holding Register |
| 0x04 | 扩展 | 厂商自定义，协议中未定义具体行为 |

| Input Register (3区) | 0x0000-0xFFFF | 30001-39999 | 125 |
| Holding Register (4区) | 0x0000-0xFFFF | 40001-49999 | 125 |

## 与标准Modbus RTU的差异说明

| 差异项 | 标准Modbus RTU | 本协议 | 原因 |
|--------|----------------|--------|------|
| 从站地址 | 1字节，从站地址 | 无 | 模组作为主站自行管理从站 |
| CRC16校验 | 2字节CRC | 无 | TCP传输层已提供校验 |
| 功能码扩展 | 仅标准功能码 | 00-06包含非标准功能码 | 适应模组管理需求 |
| 数据区前缀 | 无 | 类型+地址+长度 | 明确数据类型和Modbus区域 |

**兼容性说明:**
- 本协议在数据内容格式上与Modbus RTU保持一致
- 模组在转发Modbus请求时，需按照标准Modbus RTU格式添加从站地址和CRC16
- 服务器端无需关心底层Modbus RTU细节，仅需按照本协议格式交互
