## 一、变量配置扩展字段

为支持更灵活的数据转换和展示，变量配置新增以下字段：

| 字段名     | 类型     | 说明                                      | 默认值   |
| :------- | :------ | :-------------------------------------- | :----- |
| Scale    | float64 | 缩放因子，用于数值转换。实际值 = 原始值 × Scale + Offset | 1.0   |
| Offset   | float64 | 偏移量，用于数值转换                                  | 0.0    |
| RegCount | int     | 寄存器数量，表示该变量占用的寄存器个数                     | 1      |
| ByteOrder| string  | 字节序，支持：ABCD(大端)、BADC、CDAB、DCBA(小端)       | ABCD   |
| Unit     | string  | 单位，如 "℃"、"%"、"V" 等                         | ""     |

### 完整变量配置字段列表

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| ID | int | 主键 |
| dev_ID | int | 关联设备表的外键 |
| Var_name | varchar | 变量名称 |
| Data_type | varchar | 数据类型（1=整数, 2=浮点数, 3=定点数, 4=字符串） |
| modbus_type | varchar | Modbus区域类型（0=线圈, 1=离散输入, 3=输入寄存器, 4=保持寄存器） |
| modbus_device | int | Modbus从站地址(1-255) |
| modbus_addr | varchar | 寄存器地址(0-65535) |
| data_len | varchar | 数据长度 |
| string_len | varchar | 字符串长度（仅字符串类型） |
| Decimal_digits | int | 小数位数（定点数转换用） |
| scale | float | 缩放因子（默认1.0） |
| offset | float | 偏移量（默认0） |
| reg_count | int | 寄存器数量（默认1） |
| byte_order | varchar | 字节序（默认ABCD） |
| unit | varchar | 单位 |

## 二、InfluxDB 语义化写入

平台收到 DTU 上发的数据后，经过以下处理流程：
1. **数据解析**：根据变量配置（ByteOrder）解析原始字节
2. **数值转换**：应用 Scale 和 Offset 计算实际值
3. **语义化写入**：将处理后的数据写入 InfluxDB `device_data` measurement

`SemanticDataItem` 结构体：

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| DevSerial | string | 设备序列号 |
| VarName | string | 变量名称 |
| SlaveAddr | int | Modbus 从站地址 |
| ModbusType | int | Modbus 区域类型（0/1/3/4） |
| ModbusAddr | int | 寄存器地址 |
| ActualValue | interface{} | 实际值（缩放+偏移后的值） |
| RawValue | string | 原始值（十六进制字符串） |
| Unit | string | 单位 |

## 三、数据库 Schema 更新

执行以下 SQL 为 `variables` 和 `caching` 表新增字段：

```sql
ALTER TABLE `variables`
  ADD COLUMN `scale` float NULL DEFAULT 1.0 COMMENT '缩放因子',
  ADD COLUMN `offset` float NULL DEFAULT 0 COMMENT '偏移量',
  ADD COLUMN `reg_count` int(11) NULL DEFAULT 1 COMMENT '寄存器数量',
  ADD COLUMN `byte_order` varchar(10) NULL DEFAULT 'ABCD' COMMENT '字节序',
  ADD COLUMN `unit` varchar(20) NULL DEFAULT '' COMMENT '单位';

ALTER TABLE `caching`
  ADD COLUMN `scale` float NULL DEFAULT 1.0 COMMENT '缩放因子',
  ADD COLUMN `offset` float NULL DEFAULT 0 COMMENT '偏移量',
  ADD COLUMN `reg_count` int(11) NULL DEFAULT 1 COMMENT '寄存器数量',
  ADD COLUMN `byte_order` varchar(10) NULL DEFAULT 'ABCD' COMMENT '字节序',
  ADD COLUMN `unit` varchar(20) NULL DEFAULT '' COMMENT '单位';
```

## 六、数据流说明

```
DTU模拟器上发0x05数据（MQTT /dtu/{serial}/up）
    ↓
后端 PayloadHandler 接收并解析
    ↓
匹配变量配置（根据 slaveAddr + modbusType + modbusAddr）
    ↓
使用 ByteOrder 解析原始字节序
    ↓
应用 Scale × RawValue + Offset 计算 ActualValue
    ↓
WriteSemanticDataToInflux() 生成 SemanticDataItem
    ↓
写入 InfluxDB device_data measurement
```
