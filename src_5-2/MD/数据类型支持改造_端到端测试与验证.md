## 三、老数据处理：清空重配

由于老数据不要了，最简单安全的方式：

### 数据库清空

使用数据库管理工具（如 Navicat、phpMyAdmin 等）或直接执行 SQL：

```sql
-- 备份（可选，推荐先备份）
CREATE TABLE variables_bak AS SELECT * FROM variables;
CREATE TABLE caching_bak AS SELECT * FROM caching;

-- 清空旧数据
DELETE FROM variables;
DELETE FROM caching;
```

## 五、问题排查路径

遇到问题按顺序排查：

### 1. 后端日志 → 数据解析、写入InfluxDB问题
优先看后端服务日志：
- 是否有数据上发日志？
- 数据解析是否有错误？
- InfluxDB写入是否成功？

打开开发者工具：
- Network面板看请求是否成功

检查数据库：
- 数据是否正常写入？

- 时间戳是否正确？

确认模拟器状态：
- 配置是否正常接收？
- 数据是否正常上报？
