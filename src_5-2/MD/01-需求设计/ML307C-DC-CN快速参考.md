## 1. 设备简介

### 1.1 型号信息

| 属性 | 值 |
|------|-----|
| **型号** | ML307C-DC-CN |
| **厂商** | 中移物联网（OneMO） |
| **网络** | 中国电信定制 |
| **类型** | 4G Cat.1 工业级单芯片 DTU 模块 |
| **开发模式** | OpenCPU（你的代码直接运行在模块内部） |

### 1.2 核心亮点

- **完整单芯片方案**：无需外部 MCU，降低 BOM 成本和 PCB 尺寸
- **强大的处理能力**：614MHz ARM Cortex-R5 核心 + 4MB pSRAM + 4MB Flash
- **内置实时系统**：FreeRTOS 实时操作系统，多任务支持
- **丰富外设接口**：UART/SPI/I2C/GPIO/ADC/PWM
- **完整协议栈**：MQTT/HTTP/HTTPS/FTP/LwM2M 全部内置
- **工业级设计**：-40°C ~ +85°C 工作温度

## 4. 通信协议详解

### 4.1 MQTT 主题格式

| 方向 | 主题格式 | 示例 |
|------|---------|------|
| 上行（设备→平台） | /dtu/{设备序列号}/up | /dtu/ML307C001/up |
| 下行（平台→设备） | /dtu/{设备序列号}/down | /dtu/ML307C001/down |

### 4.2 QoS（服务质量）

| 类型 | 推荐值 | 说明 |
|------|--------|------|
| 订阅下行主题 | QoS=2 | 确保平台命令可靠到达设备 |
| 发布上行消息 | QoS=2 | 确保设备数据可靠到达平台 |

## 5. 完整功能码实现

所有功能码均在应用层直接通过 SDK 调用，无 AT 指令交互。

### 5.1 功能码 0x00 - 心跳包

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                   功能码 0x00 - 心跳包详解                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ 功能说明：设备定期发送到平台，表明设备在线                              │
│ 默认间隔：30秒                                                         │
│ 通信方向：单向（设备→平台）                                                 │
│                                                                          │
│ 协议格式：                                                                 │
│ 字节0 = 0x00（功能码）                                                      │
│ 字节1 = 0x00（保留）                                                        │
│                                                                          │
│ 示例数据：                                                                 │
│ 完整 Hex: "0000"                                                          │
│                                                                          │
│ 实现方式（OneMO SDK）：                                                      │
│ 1. 设置 30s 定时器                                                         │
│ 2. 调用 mqtt_publish("/dtu/ML307C001/up", QoS=2, payload="0000")           │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 功能码 0x01 - 模组配置查询

```
┌─────────────────────────────────────────────────────────────────────────────┐
│              功能码 0x01 - 模组配置查询详解                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 功能说明：平台查询当前模组配置参数                                      │
│ 通信方向：双向（平台→设备→平台）                                           │
│                                                                          │
│ 下行（平台→设备）：                                                          │
│ 字节0 = 0x01（功能码）                                                     │
│                                                                          │
│ 上行（设备→平台）：                                                          │
│ 字节0 = 0x01（功能码）                                                     │
│ 字节1 = 0x00（成功）/0x01（失败）                                           │
│ 字节2-3 = 上报间隔（大端序，例如 0x00 0x1E = 30秒）                      │
│ 字节4- = 其他配置参数                                                    │
│                                                                          │
│ 实现方式（OneMO SDK）：                                                      │
│ 1. 在 mqtt_on_message 回调中接收消息                                          │
│ 2. 读取当前配置（从内置 Flash）                                               │
│ 3. 组装响应消息并发布                                                         │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. 开发参考

## 7. 调试与错误处理

### 7.1 常见问题

| 问题 | 排查方法 |
|------|---------|
| 网络连接失败 | 检查 SIM 卡、信号质量（AT+CSQ 临时调试） |
| MQTT 连接失败 | 检查 Broker 地址、防火墙、客户端 ID |
| Modbus 无响应 | 检查 RS485 接线、从站地址、波特率 |
| 数据上报失败 | 检查采集点配置、定时器设置 |
