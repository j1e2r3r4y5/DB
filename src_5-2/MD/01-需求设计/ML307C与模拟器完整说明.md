```
│  └──────────────────────────────┬──────────────────────┘   │

│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 为什么需要模拟器？

在开发和测试过程中，我们不可能随时连接真实的硬件设备，所以模拟器可以：

| 优势 | 说明 |
|------|------|
| **替代真实硬件** | 不需要购买和部署真实设备 |
| **便于测试** | 可以随时启动、调试、测试 |
| **模拟各种场景** | 可以模拟网络异常、数据变化等 |
| **成本低廉** | 一台电脑就能运行 |

## 2. 真实 ML307C-DC-CN 设备详解

### 2.1 ML307C-DC-CN 是什么？

**ML307C-DC-CN** 是中移物联网（OneMO）推出的 **4G Cat.1 工业级单芯片 DTU 模块**：

| 属性 | 值 |
|------|-----|
| **型号** | ML307C-DC-CN |
| **厂商** | 中移物联网（OneMO） |
| **网络** | 中国电信定制 |
| **类型** | 4G Cat.1 工业级单芯片 DTU 模块 |
| **开发模式** | OpenCPU（你的代码直接运行在模块内部） |

**硬件规格**：

- 封装：LCC
- 尺寸：17.7mm × 15.8mm × 2.2mm
- 供电电压：3.4V ~ 4.5V（典型值 3.8V）
- 工作温度：-40°C ~ +85°C（扩展工业级）
- **协议支持**：TCP/IP、HTTP/HTTPS、MQTT、FTP、SSL、LwM2M

**接口能力**：

- UART（3路，最高 921600bps）
- USB 2.0
- SPI、I2C
- GPIO（3路，支持中断）
- ADC（2路）
- PWM（2路）
- 天线/SIM 卡接口

### 2.3 ML307C-DC-CN 内部功能分区

#### 2.3.1 应用层（你的代码）

这是你编写代码的地方，通过 OneMO SDK 调用底层 API：

- **Modbus RTU 主站**：通过 UART 接口连接 Modbus 从站设备
- **数据采集与处理**：读取传感器数据，转换为浮点数/整数
- **继电器控制**：通过 GPIO 输出高低电平控制
- **协议处理**：实现功能码 0x00~0x06 协议
- **MQTT 通信**：调用内置 MQTT 库连接平台
- **配置管理**：读写内置 Flash 存储配置

#### 2.3.2 底层系统（OneMO）

底层系统由中移物联网提供，完全透明：

- **FreeRTOS**：实时操作系统，支持多任务
- **4G LTE Cat.1 协议栈**：处理网络通信
- **内置协议库**：MQTT/HTTP/HTTPS/FTP/LwM2M
- **外设驱动库**：UART/SPI/I2C/ADC/PWM/GPIO
- **文件系统**：用于持久化存储配置
- **FOTA**：远程固件升级功能

## 4. 对比分析

### 4.1 真实设备 vs 模拟器

| 功能 | 真实 ML307C-DC-CN | 模拟器（Python） |
|-----|-------------------|----------------|
| **4G 网络连接** | 真实硬件 + 电信网络 | 普通互联网（WiFi/以太网） |
| **MQTT 协议栈** | 内置硬件协议栈（SDK 调用） | paho-mqtt 库（Python 标准库） |
| **Modbus RTU 主站** | 真实 UART 接口 + 真实设备 | 虚拟设备（内存中模拟） |
| **配置管理** | 内置 Flash 存储 | JSON/YAML 配置文件 |
| **协议处理** | 你的 C/Lua 代码 | 你的 Python 代码 |
| **GPIO/继电器** | 真实硬件引脚 | 虚拟状态变量 |
| **运行环境** | FreeRTOS 实时操作系统 | Windows/Linux 桌面操作系统 |
| **调试方式** | USB/UART 调试串口 | Print/IDE 调试 |
| **成本** | 需要购买硬件模块 | 一台电脑就能运行 |

### 4.2 共同点

无论真实设备还是模拟器，**应用层协议（功能码 0x00~0x06）完全一致**！

| 功能码 | 功能 | 实现方式 |
|-------|-----|---------|
| 0x00 | 心跳包 | 定时器触发 → MQTT 发布 |
| 0x01 | 模组配置查询 | MQTT 接收 → 读取配置 → 响应 |
| 0x02 | 模组配置下发 | MQTT 接收 → 写入配置 → 响应 |
| 0x03 | 数据配置查询 | MQTT 接收 → 读取采集点 → 响应 |
| 0x04 | 数据配置下发 | MQTT 接收 → 配置采集点 → 响应 |
| 0x05 | 数据上报 | 定时器触发 → Modbus 读取 → MQTT 发布 |
| 0x06 | 远程置数 | MQTT 接收 → 执行控制 → 响应 |

## 5. 完整数据流向示例

### 5.1 场景：数据上报（功能码 0x05）

#### 真实设备流程：

```
1. FreeRTOS 定时器触发（120s）
   │
   │
2. 应用层调用 SDK：modbus_read_holding_registers()
   │
   │ 真实 UART 发送 Modbus 请求
   │
3. Modbus 从站响应 → UART 接收
   │
4. 应用层解析数据：寄存器值 → float32（温度）
   │
5. 组装协议消息：0x05 + 数据点列表
   │
6. 调用 SDK：mqtt_publish(topic, payload)
   │
7. 底层系统通过 4G 网络发送到 Broker
```

#### 模拟器流程：

```
1. Python Timer 触发（120s）
   │
   │
2. 调用 VirtualDevice.read_registers()
   │
   │（内存中查找虚拟数据）
   │
3. 返回虚拟传感器数据
   │
4. 解析数据：与真实设备相同的代码
   │
5. 组装协议消息：0x05 + 数据点列表（完全一致）
   │
6. 调用 mqtt_client.publish()
   │
7. 发送到真实 Broker（通过 WiFi/以太网）
```

---

### 5.2 场景：远程置数（功能码 0x06，继电器控制）

#### 真实设备流程：

```
1. 平台发送 MQTT 消息（功能码 0x06，线圈 0 置 ON）
   │
   │ 4G 网络接收 → 底层系统通知应用层
   │
2. 应用层收到回调：mqtt_on_message(topic, payload)
   │
3. 解析协议，确认是功能码 0x06
   │
4. 调用 SDK：gpio_set_level(RELAY_PIN, 1)
   │
   │ 物理引脚输出高电平 → 继电器动作
   │
5. 组装成功响应消息
   │
6. 调用 mqtt_publish() 返回平台
```

#### 模拟器流程：

```
1. 平台发送 MQTT 消息（功能码 0x06，线圈 0 置 ON）
   │
   │ WiFi/以太网接收 → paho-mqtt 触发 on_message 回调
   │
2. 回调函数被调用
   │
3. 解析协议（与真实设备相同代码）
   │
4. 修改虚拟变量：virtual_device.coils[0] = True
   │
   │（无物理动作，但数据状态更新）
   │
5. 组装成功响应消息（完全一致）
   │
6. 调用 mqtt_client.publish() 返回平台
```

## 6. 总结

### 6.1 为什么模拟器可以替代真实设备？

1. **协议完全一致**：功能码 0x00~0x06 格式一模一样
2. **MQTT 通信相同**：都连接真实 Broker，发布/订阅相同主题
3. **数据格式一致**：Modbus 寄存器值 → float32/int 转换算法相同
4. **逻辑可复用**：把模拟器的 Python 代码转换为 C 代码，就能运行在真实 ML307C 上！

### 6.2 开发建议

| 阶段 | 推荐使用 | 目的 |
|------|---------|-----|
| **1. 平台和协议开发** | 模拟器 | 快速验证协议，无需硬件 |
| **2. 真实设备移植** | 模拟器 + 真实设备 | 两边对照调试 |
| **3. 生产部署** | 真实设备 | 大规模部署使用 |

### 6.3 从模拟器到真实设备的移植要点

把模拟器代码移植到真实 ML307C-DC-CN（OpenCPU）时：

| 模拟器函数 | 真实设备 SDK 函数 | 变化 |
|-----------|----------------|------|
| `mqtt_client.publish()` | `mqtt_publish()` | 库不同，但用法相似 |
| `threading.Timer(120, fn)` | `os_timer_create(120, fn)` | 定时器 API 不同 |
| `json.load(config.yaml)` | `fs_read() + 配置解析` | 配置存储方式不同 |
| `VirtualDevice.read_registers()` | `modbus_read_holding_registers()` | Modbus 库不同 |
