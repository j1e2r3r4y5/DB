## 🚀 完整部署步骤

---

### 第一步：启动 InfluxDB

1. 进入 InfluxDB 目录：
   ```
   cd c:\Users\JERRY\influxdb2\influxdb2_windows_amd64
   ```

2. 启动 influxd.exe：
   ```
   直接双击 influxd.exe 或在终端中运行
   ```

3. 验证：检查端口 `8086` 是否在监听
   ```
   netstat -ano | findstr :8086
   ```

---

### 第二步：启动后端服务

1. 进入后端目录：
   ```
   cd c:\Users\JERRY\Desktop\gp\src_5-2\dev _back_end\dev
   ```

2. 编译并启动（如果修改了代码）：
   ```
   go build -o dev.exe main.go
   ```

3. 启动后端：
   ```
   直接双击 dev.exe
   ```

4. 验证：检查端口 `8000` 是否在监听
   ```
   netstat -ano | findstr :8000
   ```

---

### 第三步：启动前端

1. 进入前端目录：
   ```
   cd c:\Users\JERRY\Desktop\gp\src_5-2\4G_dev_front\4G_dev
   ```

2. 安装依赖（首次部署）：
   ```
   npm install
   ```

3. 启动开发服务器：
   ```
   npm run dev
   ```

4. 访问前端：
   ```
   http://localhost:4326
   ```

---

### 第四步：启动模拟器

1. 进入模拟器目录：
   ```
   cd c:\Users\JERRY\Desktop\gp\src_5-2\simulator_v3
   ```

2. 安装依赖（首次部署）：
   ```
   pip install -r requirements.txt
   ```

3. 运行模拟器：
   ```
   python main.py
   ```

4. 验证：检查端口 `502`（Modbus）和 `1883`（MQTT Broker 单独运行）

## 🧰 清理与重置操作

### 重置 InfluxDB 数据

1. 使用 Influx CLI 删除并重建 bucket：
   ```bash
   cd c:\Users\JERRY\influxcli
   .\influx.exe bucket delete --name mybucket --org myorg
   .\influx.exe bucket create --name mybucket --org myorg --retention 0
   ```

### 重置数据库变量

1. 使用 Python 脚本（`fix_and_deploy.py`）：

   cd c:\Users\JERRY\Desktop\gp\src_5-2
   python fix_and_deploy.py

2. 这个脚本会自动：

   - 添加上面表格中的新变量
